# 🎬 QuickShow – MERN Movie Ticket Booking System

**QuickShow** is a fully functional **full-stack MERN movie ticket booking web application** built with **Inngest**, **Nodemailer**, **Stripe**, and **Clerk** — delivering a seamless, secure, and user-friendly movie booking experience.

---

## 🚀 Features

- 🎟️ Book movie tickets with **live seat selection**
- 🔐 Authentication powered by **Clerk**
- 💳 Secure payments using **Stripe**
- 📧 Email notifications with **Nodemailer**
- ⏱️ Background jobs and event workflows using **Inngest**
- 🧾 Admin dashboard to manage **movies, shows, and revenue**
- 📊 Monthly **revenue & booking analytics**
